# bot/sites — adaptadores de portais

Cada arquivo aqui é um **descritor de portal** (não automação pronta): define a
URL de busca, a dica de filtro remoto e de onde vêm os termos daquela rodada. Quem
abre o Chrome e aplica é o modelo, seguindo [`../prompt_loop.md`](../prompt_loop.md).

- **Base para novos portais:** [`_template.sh`](_template.sh)
- **Guia completo + contrato:** [`../../docs/ADAPTERS.md`](../../docs/ADAPTERS.md)

Adicionar um portal é o PR mais fácil e mais útil que você pode mandar. 🙌
